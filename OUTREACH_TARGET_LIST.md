# Outreach Target List — Islamic Travel Blogs & Forums
*Day 24 of PLAN_30_DAY.md*

This is a research list for **manual, external outreach** by the business owner — not something I can execute (it requires real human relationship-building, and in forums, genuine non-promotional participation). Every entry below is a real, currently-live site found via web search on 2026-09-03, not a guess. Domain Authority (DA) figures are as reported by Feedspot's directory pages and are a rough popularity signal, not something to over-index on.

**Ground rule carried over from the rest of this project: no fabricated claims in outreach either.** Any pitch to these sites should describe Saudi Cabs GMC only using facts already verified on the site itself (routes served, vehicle types, WhatsApp booking, fixed/route-based fares) — the same standard already applied to the site's own copy.

## Category 4 — TripAdvisor destination forums (high-traffic, strict rules)

Not "Islamic" specifically, but these are the single highest-traffic places people actually ask "which taxi/transport should I use in Makkah/Madinah" — verified via search that these threads are current and active. **TripAdvisor explicitly prohibits self-promotion in forum posts** (no links, no "use my company"); any participation here must be genuinely helpful advice under a normal profile, never a pitch. Listed because the questions being asked are a direct match for this business, not because they're a link-building channel.

## Not pursued: Urdu/Pakistani-specific Hajj blogs

Given the business uses a Pakistani WhatsApp number and likely serves Pakistani/Urdu-speaking pilgrims, I specifically searched for Urdu-language Hajj/Umrah blogs as a targeted angle. What turned up were mostly PDF guide downloads, mobile apps, and scanned guidebooks rather than active blogs that publish ongoing content or accept outreach — not a fit for backlink outreach. If the owner knows of specific active Urdu-language Umrah blogs or Facebook groups from their own network, those would likely outperform anything findable via generic search.

## How to use this list

1. Start with Category 1 (best topical fit, several mid-DA sites likely to actually respond) and Category 3 (free, no approval needed — just answer real questions honestly).
2. Category 2's top entries (Crescentrating, Halal Booking) are worth a genuine pitch but are higher-authority and likely slower/harder to land — good stretch targets, not the first move.
3. Category 4 is not a backlink channel — treat it as reputation-building / potential referral traffic only, and follow each platform's no-self-promotion rules exactly.
4. Any outreach email or forum post should link to real, existing site content (e.g. `/jeddah-airport-guide`, `/makkah-transport-guide`, `/hajj-transport-faq`) — never a generic homepage pitch.
